Les commandes Linux de base

Commande Description Exemple
pwd Affiche le répertoire courant pwd
ls Affiche les fichiers et dossiers ls -l
cd Permet de changer de répertoire cd Documents
mkdir Crée un nouveau dossier mkdir projet
touch Crée un nouveau fichier touch index.html
cp Copie un fichier ou un dossier cp fichier.txt sauvegarde.txt
mv Déplace ou renomme un fichier mv ancien.txt nouveau.txt
rm Supprime un fichier rm fichier.txt
rmdir Supprime un dossier vide rmdir dossier
cat Affiche le contenu d'un fichier cat fichier.txt
clear Efface le contenu du terminal clear
whoami Affiche l'utilisateur actuel whoami
date Affiche la date et l'heure date
man Affiche le manuel d'une commande man ls
sudo Exécute une commande avec les droits administrateur sudo apt update
